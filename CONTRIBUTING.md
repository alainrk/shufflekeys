# Contributing to ShuffleKeys

Thank you for your interest in ShuffleKeys! We welcome contributions from the community.

## How to Contribute

1.  **Report Bugs:** Open an issue on GitHub describing the bug and how to reproduce it.
2.  **Suggest Features:** Open an issue to discuss new features or improvements.
3.  **Submit Pull Requests:**
    *   Fork the repository.
    *   Create a new branch for your feature or bugfix.
    *   Ensure your code follows the existing style and passing all tests.
    *   Submit a pull request with a clear description of your changes.

## Development Setup

See the [README.md](README.md) for build and installation instructions.

### Code Quality

Before submitting a PR, please run:

```bash
make lint
make test
```

We use `clippy` for Rust linting and `rustfmt` for formatting.
